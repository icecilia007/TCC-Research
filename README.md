# Integração de Inteligência Artificial e Biomarcadores Neurofisiológicos para Apoio ao Diagnóstico de Transtornos Mentais e do Neurodesenvolvimento

O presente trabalho tem como objetivo desenvolver uma pesquisa que utilize técnicas de inteligência artificial para apoiar o diagnóstico de transtornos mentais e transtornos do neurodesenvolvimento. A investigação integrará dados de eletrorretinografia, dados demográficos, questionários padronizados, eye tracking e outros dados neurofisiológicos relevantes, visando a criação de um sistema robusto que potencialize a identificação precoce e precisa dessas condições.
